## 🔬 System Overview
The HL7 ORM Order Intake Interface Specification module serves as the primary data ingress point for the **Akai Community Hospital EHR & Informatics Sytem**. It intercepts inbound HL7 `ORM^O01` order messages, enforces strict data validation rules, assigns globally unique accession identifiers, and queues validated specimens for analytical instrumentation.

---

## 🗂️ Data Dictionary: Inbound Specimen Payload

This data dictionary defines the raw elements extracted from incoming `ORM^O01` messages and required for initial accessioning into the relational database.

| Field Name | Source Segment | Target SQL Type | Nullable | LOINC / Standard Mapping | Validation & Business Constraints |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `message_control_id` | `MSH-10` | `VARCHAR(32)` | **NO** | IEEE 11073 | Must be globally unique. Duplicates trigger an `ACK^AR` (Application Reject) response. |
| `mrn` (Medical Record #) | `PID-3.1` | `VARCHAR(16)` | **NO** | Master Patient Index | Primary identifier. Format regex: `^MRN-[0-9]{8}$`. |
| `patient_dob` | `PID-7` | `DATE` | **NO** | ISO 8601 (`YYYYMMDD`)| Must be a valid past date: `patient_dob <= CURRENT_DATE`. |
| `patient_sex` | `PID-8` | `VARCHAR(2)` | **NO** | HL7 Table 0001 | Constrained to `'M'`, `'F'`, `'U'`, `'A'` (Ambiguous). |
| `encounter_type` | `PV1-2` | `VARCHAR(3)` | **NO** | HL7 Table 0007 | Constrained to `'I'` (Inpatient), `'O'` (Outpatient), `'E'` (Emergency). |
| `placer_order_number` | `ORC-2` | `VARCHAR(32)` | **NO** | EHR Order Ref | Unique order ID generated by Epic. Format: `^ORD-[0-9]{10}$`. |
| `loinc_code` | `OBR-4.1` | `VARCHAR(10)` | **NO** | LOINC Database | Must map to an active record in `Test_Catalog` (e.g., `2345-7` for Glucose). |
| `specimen_source` | `OBR-15.1` | `VARCHAR(16)` | **NO** | SNOMED-CT | Constrained to valid tissue/fluid types: `'SER'`, `'PLAS'`, `'URINE'`, `'WB'`, `'CSF'`. |
| `collection_timestamp` | `OBR-7` | `TIMESTAMPTZ` | **NO** | ISO 8601 | Cannot be in the future. Must be `<= CURRENT_TIMESTAMP`. |
| `priority_flag` | `ORC-7.6` | `VARCHAR(5)` | **NO** | HL7 Table 0027 | Constrained to `'ROUTINE'`, `'STAT'`, `'TIMED'`, `'URGENT'`. |
